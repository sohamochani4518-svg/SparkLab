**LED Blinker**

**Description**

I made a project with Arduino. This project is about using an Arduino Uno to make an LED blink on and off at times.

**Components Used**

- Arduino Uno

- LED

- 330Ω resistor

- Breadboard

- Jumper wires

**Working**

The Arduino Uno sends signals to the LED pin. These signals turn the LED on and off. There is a pause between each time the LED is turned on and off. The Arduino Uno is what controls the LED and makes it blink.

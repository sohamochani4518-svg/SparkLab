**Binary Number Counter Using 4 LEDs** 🔢

**Description**

This project demonstrates binary number counting using 4 LEDs connected to an Arduino.

The LEDs represent 4 binary bits and display numbers from 0 to 15 in binary format.

**Components Used**

- Arduino Uno
- 4 LEDs
- 220Ω/330Ω resistors
- Breadboard
- Jumper wires

**Concepts Learned**

- Binary numbers
- Digital output control
- Loops
- Bit operations

**Working**

Each LED represents a binary digit.

The 4 LEDs can display values from:

- 0000 → 0
- 1111 → 15

The Arduino changes the LED states to show each binary number.

**Code**

`Binary_counter_using_LED.ino`

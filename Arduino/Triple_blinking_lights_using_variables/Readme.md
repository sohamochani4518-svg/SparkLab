**Triple Blinking Lights Using Variables** 💡💡💡

**Description**

This project controls three LEDs connected to an Arduino.

Each LED blinks at different intervals using variables to store pin numbers and timing values.

**Components Used**

- Arduino Uno
- 3 LEDs
- 3 resistors (220Ω/330Ω)
- Breadboard
- Jumper wires

**Concepts Learned**

- Multiple LED control
- Using variables in Arduino
- Digital output pins
- delay() function

**Working**

Three LEDs are connected to different Arduino pins.

Variables are used to make the code easier to modify instead of repeatedly writing pin numbers and timings.
